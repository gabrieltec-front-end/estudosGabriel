o git pull apos feitas alteraçoes e feito o seu comite,antes de subir ele para o repositorio é bastante comum usar o comando 
git pull...>este comando atualiza o repositorio local com as atualizações mais recentes feito no repositorio remoto,sendo assim atualiza o seu repositorio local
,logo em seguida um git push padrão para subir as alterações feitas no repositorio local para o remoto 



git log é como se exibisse no proprio terminal um historio sobre os arquivos e seu versionamento


tipos de git log

git log --oneline resumi os commits em uma linha para ficar facil a exibição

git --stat exibi quais arquivos foram alterados e quantas linhas foram alteradas
git log -p exibi todas as alterações feitas em cada commit ou seja em cada atualização(exibi uma lista muito grande)


usados agora para fazer pesquisas

git de pesquisas no commit
git log --author="Texto do qual quer pesquisar"pesquisa pelos commit o nome do author responsavel pelo aquele commit


git log --grepe="Pesquisa o texto desjado dentre os commits"




git log --graph="est command bem legal exibi uma ramificaçao dos commits de onde começou por onde passou até o ponto atual"
